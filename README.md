# AI & ML Learning Projects

A collection of three interactive, responsive, browser-based educational tools for learning Artificial Intelligence and Machine Learning concepts.

The project was created for the BSERC GENAI Internship and uses only HTML, CSS, and vanilla JavaScript. It requires no server, package installation, API key, or backend.

## Applications

### 1. AI & ML Learning Hub

Open [ai_ml_dashboard.html](./ai_ml_dashboard.html).

A learning dashboard for tracking study progress and exploring core AI and ML topics.

Features:

- Home, AI Concepts, Learning Progress, Quiz, and Flashcards navigation
- Search and category filters for learning topics
- Topic completion tracking and progress percentages
- Five-question interactive quiz with answer feedback
- Click-to-reveal educational flashcards
- Learning activity history
- Dark and light themes
- Reset progress, quiz, and activity data
- Data saved locally with `localStorage`

### 2. AI & ML Interactive Presentation

Open [interactive_ai_presentation.html](./interactive_ai_presentation.html).

A ten-slide educational presentation about Artificial Intelligence and Machine Learning, with a final knowledge quiz.

Features:

- Next and previous slide controls
- Slide indicators and slide menu
- Left/right arrow-key navigation
- Presentation progress bar
- Interactive AI, ML, and deep learning comparison
- Clickable machine learning type cards
- Five-question quiz with final score
- Restart presentation and quiz controls
- Fullscreen mode
- Dark and light themes

### 3. Machine Learning Model Explorer

Open [ml_model_explorer.html](./ml_model_explorer.html).

An educational prediction simulator for experimenting with three common machine learning approaches.

Features:

- Linear Regression, Decision Tree, and K-Nearest Neighbors models
- Student performance inputs for study hours, attendance, and previous test score
- JavaScript-generated prediction results
- Random sample and reset controls
- Simulated training dataset table
- SVG scatter-chart visualization
- Algorithm comparison and model explanations
- Decision tree visualization
- Dark and light themes

> This application uses a small simulated dataset and is intended only for learning. Its predictions are not a validated academic or statistical model.

## Getting Started

No build process or dependencies are required.

1. Download or clone this repository.
2. Open the `Project_2` folder.
3. Open any application HTML file directly in a modern browser:
   - `ai_ml_dashboard.html`
   - `interactive_ai_presentation.html`
   - `ml_model_explorer.html`

You can also use VS Code Live Server, although it is not required.
