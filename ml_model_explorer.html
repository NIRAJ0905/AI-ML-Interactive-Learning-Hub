How Linear Regression works

Linear Regression finds a mathematical relationship between input features and a continuous output. It fits a line that minimizes the squared prediction errors.

Mathematical formula:

y = b₀ + b₁x₁ + b₂x₂ + b₃x₃

Here, x₁, x₂ and x₃ represent study hours, attendance and previous score.

06. Algorithm Comparison

Understand the differences between the three machine learning approaches.

📈 Linear Regression

Regression

Learns a weighted mathematical relationship between features and the target.

InterpretabilityHigh
ComplexityLow

Useful for: Predicting marks, prices and trends.

🌳 Decision Tree

Rule-based model

Makes predictions by following a sequence of feature-based decision rules.

InterpretabilityHigh
ComplexityMedium

Useful for: Classification, decision systems and risk analysis.

📍 K-Nearest Neighbors

Instance-based learning

Finds similar training examples and combines their target values.

InterpretabilityMedium
ComplexityMedium

Useful for: Recommendation systems, pattern recognition and similarity analysis.
