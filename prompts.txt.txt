- Include a student-friendly interface.

IMPORTANT:

- Do not leave placeholder buttons.

- Ensure there are no JavaScript errors.

PROMPT 3: MACHINE LEARNING MODEL EXPLORER
Act as an expert frontend developer, machine learning educator and UI/UX designer.

Create a complete, professional, interactive web application titled:

"Machine Learning Model Explorer"

PURPOSE:
Help college students understand how machine learning algorithms work through interactive visual experiments.

TECHNICAL REQUIREMENTS:
1. Use only HTML, CSS and vanilla JavaScript.
2. Everything must be inside ONE single HTML file.
3. No React, backend, external APIs or paid libraries.
4. Must work by opening the HTML file directly in a browser.
5. Responsive for desktop, tablet and mobile.
6. Use realistic sample datasets and clearly label them as simulated data.

APPLICATION SECTIONS:

1. Introduction
Explain machine learning and its basic workflow:
Data → Training → Model → Prediction.

2. Algorithm Explorer
Include three algorithms:
- Linear Regression
- Decision Tree
- K-Nearest Neighbors (KNN)

Allow users to select an algorithm and display a simple explanation of how it works.

3. Interactive Dataset
Create a sample dataset for student performance with:
- Study hours
- Attendance percentage
- Previous test score
- Final score

Allow users to change sample input values using sliders or input fields.

4. Prediction Simulator
Use actual JavaScript calculations to generate sample predictions.
- Linear Regression: implement a simple regression calculation.
- KNN: calculate distances from sample training records and predict using nearest neighbors.
- Decision Tree: implement a simple rule-based decision tree and explain that it is an illustrative model.

Show the prediction and explain which input values influenced it.

5. Visualizations
Display:
- Sample data table.
- Simple CSS or SVG visualization of the data.
- Prediction result card.
- Comparison of the three algorithms.

INTERACTIVE FEATURES:
1. Algorithm selection.
2. Study hours slider.
3. Attendance slider.
4. Previous score slider.
5. Predict button.
6. Random sample data button.
7. Reset button.
8. Show/hide explanation button.
9. Light/dark mode toggle.
10. At least one interactive chart or visual representation.

DESIGN:
- Professional educational dashboard.
- Modern cards and clean typography.
- Attractive but readable layout.
- Clear labels and tooltips.
- Good mobile responsiveness.

IMPORTANT:
- All controls must work.
- Predictions must be calculated by JavaScript, not hardcoded.
- Use a small, clearly identified sample dataset.
- Explain that this is an educational simulation, not a validated predictive model.
- Add comments to important JavaScript functions.
- Ensure no JavaScript errors.
- Include all code in one HTML file.
- Output the complete code in one code block.
- Do not omit any part of the code.
